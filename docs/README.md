## A note on the numbers

`PROJECT_EXPLAINER.md` predates the final analysis run and reports Fisher separability and activation patching values from an earlier pass. The authoritative numbers are the ones printed in the notebook outputs, which the top level README quotes directly. The qualitative conclusions match across both.
